# TvToolbar

Prosta aplikacja na Android TV z dolnym paskiem narzędzi (3 przyciski).
Obsługuje mysz (krótkie i długie kliknięcie).

- **Pliki:** uruchamia menedżer plików (długie kliknięcie = wybór z listy).
- **Przeglądarka:** uruchamia przeglądarkę (długie kliknięcie = wybór z listy).
- **Opcje:** otwiera ustawienia Wi-Fi (długie kliknięcie = pełne ustawienia).
